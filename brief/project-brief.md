# Project Brief: agent-tool-gateway

- **仓库与本地目录名**：`agent_tool_gateway`（GitHub：`lingjj59/agent_tool_gateway`）
- **课题名称**：`agent-tool-gateway`（面向 AI Agent 的受控工具执行网关与审计回放系统）
- **阶段**：Commit 1（开题立项）
- **技术栈**：Python 3.11+、FastAPI、SQLite、YAML 策略、Pytest、CLI（纯后端、全本地假数据、零外网）

---

## 1. 一句话需求

构建一个面向 AI Agent 的受控工具执行网关与审计回放系统（`agent-tool-gateway`），在全本地、零外网的模拟环境下，对工具调用强制执行角色授权与目录隔离、会话预算、幂等保护、宿主 Token 隔离审批及最新策略同步复核，并以 SQLite 状态库与防注入 JSONL 审计日志留下可独立复核的完整证据链。

---

## 2. 核心三步业务流程

1. **Step 1｜调用受理与前置防线（鉴权 · 预算 · 幂等）**
   - Agent 携带角色标识、会话 ID 与幂等键请求执行 4 个模拟工具之一（`read_doc`、`query_tickets`、`create_ticket`、`send_email`）。
   - 网关校验角色权限、路径边界与会话预算：**越权或目录越界统一返回 `403`**，**超出预算返回 `429`**，且**所有被拒请求同样计入会话预算**；随后校验幂等键：**同参去重返回原结果（`200`）**，**异参复用同一幂等键返回冲突（`409`）**。
2. **Step 2｜受控执行、隔离审批与同步二次复核**
   - `read_doc` 严格限定在授权目录 `sandbox/public/` 内读取并拦截 `../` 与 URL 编码路径穿越（隔离目录 `sandbox/secret/` 严禁读取），合法文档中若包含假敏感标记（`CANARY_*`），响应正文必须打码为 `[REDACTED]`。
   - `query_tickets` 查询 SQLite 假工单（含预置间接提示词诱导文本的工单样本）；`create_ticket` 写入本地 SQLite 假工单并返回 `200`。
   - 高风险工具 `send_email` 不允许直接落盘发送，先创建待审批记录并返回 **`202`**；宿主侧凭隔离凭据 **`X-Host-Token`** 发起批准时，**同步按当前最新生效 YAML 策略执行二次复核（无“已批未执行”中间态）**——通过则写入本地假发件箱，若策略已升版撤权则统一返回 **`403`**、审批单置为 **`REJECTED`**、原因记为 **`POLICY_REVOKED_BEFORE_EXECUTION`**。
3. **Step 3｜状态落盘、JSONL 审计与回放核查**
   - **SQLite 状态库**持久化会话/预算计数、幂等记录、审批单、假工单与本地假发件箱状态；**单行序列化 JSONL 审计日志**记录每次请求、裁决、拒绝原因与审批轨迹，防换行符注入且**严禁保存 `X-Host-Token` 或任何假密钥原文**。
   - 通过 CLI 回放会话轨迹、SQLite 状态与假发件箱记录，供 Pytest 验收、结对对抗与轻量评价 Agent 独立核验。

## 3. Goal 与 Non-goal

### Goal（首版必须做到）
- **固定角色与预算边界**：严格实现 3 个角色——`reader_agent`（仅只读工具，会话上限 8 次）、`ops_agent`（可申请全部 4 个工具，其中 `send_email` 须人工审批，会话上限 8 次）、`budget_test_agent`（仅只读工具，会话上限 3 次）。
- **固定 4 个本地模拟工具**：`read_doc`（区分 `sandbox/public/` 与 `sandbox/secret/`，拦路径穿越并打码 `CANARY_*` 为 `[REDACTED]`）、`query_tickets`（含间接诱导文本假工单）、`create_ticket`、`send_email`（写入本地假发件箱，需人工审批）。
- **锁定状态码与核心语义**：正常执行与同参幂等去重返回 `200`；高风险待审批返回 `202`；越权、目录隔离拦截与撤权拦截统一返回 `403`；幂等异参冲突返回 `409`；会话超预算返回 `429`；被拒请求计入会话预算；审计日志采用单行 JSONL 且严禁存假密钥原文。
- **纵向交付与课程验证**：按 `T-01`—`T-06` 纵向切片交付并冻结 `v0.1` 基线，随后完成 E1 实验、轻量评价 Agent（3–4 只读工具 + 确定性预检 + 1 次 LLM 判读 + K1–K6 校准 + `score_suggestion: null` + 人工签署）、E2 策略升版撤权、E3 4 方向受控对抗及干净环境交接。

### Non-goal（首版明确不做）
- 不开发任何 Web 前端页面、浏览器控制台或图形界面（GUI）。
- 不接入真实互联网、真实 SMTP 邮件服务、真实工单系统或真实用户/学生隐私数据。
- 不实现分布式多节点调度、外部 OAuth/SSO 身份中心或自动水平扩缩容。
- 不构建通用型多 Agent 编排大平台；评价 Agent 保持受限只读工作流，**不替代人类打分或自动给出最终成绩**。

## 4. 核心不变量（Invariants）

| 编号 | 不变量名称 | 精确约束描述 |
| :--- | :--- | :--- |
| **INV-01** | **授权隔离与零泄密不变量** | 任何角色越权、`sandbox/secret/` 访问或路径穿越（含 `../` 与 URL 编码）均必须返回 `403` 且不产生工具副作用；合法文档中的 `CANARY_*` 标记在响应正文中必须打码为 `[REDACTED]`；单行 JSONL 审计日志严禁包含换行符注入与 `X-Host-Token` / 假密钥原文。 |
| **INV-02** | **预算单调与幂等唯一不变量** | 每个会话的预算计数器单调递增，**所有请求（含 `403`、`409` 等被拒请求）均扣减预算**，达到角色上限（8/8/3）后一律返回 `429`；同一幂等键同参请求返回 `200` 且最多产生 1 次副作用，异参复用同一幂等键返回 `409` 且严禁覆写首次记录。 |
| **INV-03** | **审批隔离与同步策略复核不变量** | `send_email` 提交后仅进入待审批状态（`202`），只有携带有效 `X-Host-Token` 的宿主审批请求才能触发批准；批准动作**同步按当前最新生效 YAML 策略执行二次复核**（无“已批未执行”中间态），策略已撤权则统一返回 `403`、置审批单为 `REJECTED` 并记 `POLICY_REVOKED_BEFORE_EXECUTION`。 |

## 6. 人机责任分工与被拒绝的 AI 建议（O1）

### 人机责任边界
- **人类负责（Decision & Sign-off）**：确定角色/预算/状态码口径（`200`/`202`/`403`/`409`/`429`）、`sandbox/public/` vs `sandbox/secret/` 与 `X-Host-Token` 隔离语义、同步复核裁决（`OQ-02`）、E1–E3 实验冻结条件与边界、以及对评价 Agent 输出的最终人工核验与签署。
- **AI 辅助（Draft & Verify Within Bounds）**：在已批准契约与 `AGENTS.md` Harness 约束内按 `T-01`—`T-06` 纵向切片起草代码与测试、排查静态/运行问题；**严禁** AI 擅自修改核心口径、提前跨轮生成代码、伪造证据或替代人类签署结论。

### 已明确拒绝的 AI 建议（至少 2 条）
| 序号 | 被拒绝的 AI 建议 | 拒绝理由与对应工程原则 |
| :--- | :--- | :--- |
| **R-01** | “被角色授权或目录规则拒绝的请求（`403`）没有执行后端工具，建议不计入会话预算，以免浪费 Agent 正常额度。” | **拒绝**。若被拒请求不扣预算，失控或对抗 Agent 可在同一会话内无限次试探工具列表、路径穿越或枚举权限边界。必须坚持“**被拒请求计入会话预算**”，超限返回 `429`。 |
| **R-02** | “将审批‘批准’与‘执行’拆成两个异步阶段，批准后先标记为 `APPROVED_PENDING_EXECUTION`，后续再异步执行且不再二次读 YAML 策略。” | **拒绝**。异步中间态既增加无必要复杂度，又会在策略升版撤权（E2）时制造 TOCTOU 越权窗口。最终拍板：**批准时同步执行最新策略二次复核（无“已批未执行”中间态）**，已撤权则返回 `403`、置为 `REJECTED` 并记 `POLICY_REVOKED_BEFORE_EXECUTION`。 |
| **R-03** | “为方便排查问题，在审计日志里保留完整请求头（含 `X-Host-Token`）与未经转义的原始文本，且异参复用幂等键时直接覆盖旧参数。” | **拒绝**。日志留存密钥原文违背数据合规红线，未转义换行符会引入 JSONL 日志注入风险，异参静默覆盖会破坏 `INV-02`。坚持**单行序列化 JSONL 零密钥原文**且**异参严格返回 `409`**。 |
